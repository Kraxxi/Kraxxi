Ares is a long-term solo project that I've been working on since June 2020. The player is the first human to set foot on Mars, and it is up to them to gather resources, construct a base and explore the planet. The goal is to create a cozy survival game with a loose story, allowing the player to decide how they want to enjoy the game.

I'm currently working on a vertical slice of the project which covers the following gameplay elements:
* Resource gathering
* Inventory & Crafting
* Tech tree & research
* Base building
* Saving/Loading
* Procedurally generated areas
* NPCs & Dialogue
